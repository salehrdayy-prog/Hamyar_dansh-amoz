مجموعه تهی

بدون عضو

{ } یا ∅

📖 نمایش مجموعه

📌 نمایش با اعضا ( roster )

اعضا را داخل {} می‌نویسیم:

A = { ۱, ۲, ۳, ۴, ۵ }

📌 نمایش با شرط ( set-builder )

ویژگی اعضا را می‌نویسیم:

A = { x | x عدد طبیعی کوچک‌تر از ۶ }

📌 نمادها

∈ = عضویت دارد

∉ = عضویت ندارد

⊂ = زیرمجموعه است

∅ = مجموعه تهی

💡 نکات مهم

📌 ترتیب اعضا مهم نیست

{1, 2, 3} = {3, 1, 2} ✓

📌 تکرار اعضا حذف می‌شود

{1, 1, 2, 3} = {1, 2, 3} ✓

📌 عضویت و عدم عضویت

۲ ∈ {1, 2, 3} ✓ (عضو است)

۵ ∉ {1, 2, 3} ✓ (عضو نیست)
