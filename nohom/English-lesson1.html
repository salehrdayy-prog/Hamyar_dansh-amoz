🌍 Lesson 1

Saving Nature

🌍 درباره این درس

در این درس با کلمات و اصطلاحات مربوط به طبیعت و محیط زیست آشنا می‌شوی.

🌳

Nature

طبیعت

tree · forest · river
♻️

Protect

محافظت کردن

save · protect · clean
🌎

Environment

محیط زیست

pollution · waste · recycle

📖 Reading — متن درس

روی هر جمله بزن تا تلفظش رو بشنوی

Nature is beautiful. We must protect it.

There are many trees, rivers, and animals in nature.

We should not cut trees. We should not throw waste in rivers.

We should plant trees and save water.

If we don't save nature, our children will not have a good life.

🇮🇷 ترجمه فارسی

طبیعت زیباست. ما باید از آن محافظت کنیم.

درختان، رودها و حیوانات زیادی در طبیعت وجود دارند.

ما نباید درختان را قطع کنیم. نباید زباله در رودها بیندازیم.

ما باید درخت بکاریم و در آب صرفه‌جویی کنیم.

اگر طبیعت را حفظ نکنیم، فرزندانمان زندگی خوبی نخواهند داشت.

💡 نکات مهم متن

📌 There is / There are

There is + اسم مفرد → There is a tree.

There are + اسم جمع → There are trees.

📌 If clause (جمله شرطی)

If + حال ساده , آینده ساده

If we don't save nature, our children will not have a good life.

📌 ضمایر مفعولی

it (آن) / them (آن‌ها) / us (ما را) / our (مالِ ما)

🔤 واژگان درس ۱

روی 🔊 هر کارت بزن تا تلفظ صحیح رو بشنوی

🎓 گرامر: must / should

📌 must = باید (قوی‌تر)

برای اجبار و کارهای ضروری استفاده می‌شود.

We must protect nature.
ما باید از طبیعت محافظت کنیم.
We must save water.
ما باید آب را ذخیره کنیم.

📌 should = بهتر است / باید (ملایم‌تر)

برای توصیه و پیشنهاد استفاده می‌شود.

We should plant trees.
بهتر است درخت بکاریم.
We should help animals.
بهتر است به حیوانات کمک کنیم.

📌 must not = نباید

برای منع و ممنوعیت.

We must not cut trees.
ما نباید درختان را قطع کنیم.
You must not smoke.
تو نباید سیگار بکشی.

📌 should not = بهتر است نکنیم

برای توصیه منفی.

We should not throw waste.
بهتر است زباله نیندازیم.
You should not lie.
بهتر است دروغ نگویی.

📊 جدول خلاصه

فارسی انگلیسی مثال
باید (ضروری) must We must help.
بهتر است should We should go.
نباید must not You must not smoke.
بهتر است نکنیم should not You should not lie.
