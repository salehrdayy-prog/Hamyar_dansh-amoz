📖 مفاهیم مهم

📌 ریشه (جواب) معادله

عددی که اگر به‌جای متغیر بگذاریم، تساوی برقرار شود.

در 2x + 3 = 7 → x = 2 ریشه است.

📌 حل معادله

پیدا کردن مقدار متغیر به‌طوری که دو طرف تساوی برابر شوند.

📌 معادله همانی

برای هر مقدار متغیر برقرار است — 2(x+1) = 2x+2

📌 معادله بی‌جواب

هیچ مقداری آن را برقرار نمی‌کند — x + 1 = x + 2

💡 اصول حل معادله

📌 قانون طلایی

هر عملی که روی یک طرف معادله انجام می‌دهی، باید روی طرف دیگر هم انجام دهی.

📌 انتقال به طرف دیگر

وقتی عضوی را از یک طرف به طرف دیگر می‌بریم، علامتش عوض می‌شود:

x + 3 = 7 → x = 7 − 3 = 4

📌 ضرب و تقسیم

2x = 8 → x = 8 ÷ 2 = 4

1️⃣ معادله درجه اول

روی هر دسته بزن تا اطلاعات کامل را ببینی

📐 مثال حل گام‌به‌گام

حل معادله: 3x + 5 = 20
۱ 3x + 5 = 20
۲ 3x = 20 − 5
۳ 3x = 15
✓ x = 5

2️⃣ معادله درجه دوم

روی هر دسته بزن تا اطلاعات کامل را ببینی

📐 فرمول حل معادله درجه دوم

📐 فرمول عمومی (دلتا)
x = −b ± √(b² − 4ac)2a
Δ = b² − 4ac (مبیّن)
📌 حالت‌های Δ

Δ > ۰ → دو ریشه حقیقی متمایز

Δ = ۰ → یک ریشه مضاعف

Δ < ۰ → ریشه حقیقی ندارد

📐 مثال حل با تجزیه

حل معادله: x² − 5x + 6 = 0
۱ x² − 5x + 6 = 0
۲ (x − 2)(x − 3) = 0
✓ x = 2 یا x = 3

🔗 دستگاه معادلات

روی هر روش بزن تا اطلاعات کامل را ببینی

📐 مثال حل دستگاه

حل دستگاه: x + y = 5 و x − y = 1
۱ x + y = 5
۲ x − y = 1
۳ جمع دو معادله: 2x = 6
✓ x = 3 و y = 2
