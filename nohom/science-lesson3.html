به دنبال محیط فعال

⚗️ محیط فعال چیست؟

محیط فعال (واکنش‌گر) ماده‌ای است که می‌تواند با مواد دیگر واکنش دهد و مواد جدید بسازد.

🧪

اسید

طعم ترش، pH کمتر از ۷

HCl · H₂SO₄ · سرکه
🧼

باز

طعم تلخ، pH بیشتر از ۷

NaOH · KOH · صابون
⚖️

خنثی

نه اسید، نه باز

آب خالص · نمک

📖 خصوصیات اسید و باز

🧪

اسیدها

  • مزه ترش دارند
  • کاغذ pH را قرمز می‌کنند
  • با فلزها واکنش می‌دهند
  • با بازها نمک + آب می‌سازند
  • مثال: سرکه، آب لیمو، HCl
🧼

بازها

  • مزه تلخ دارند
  • کاغذ pH را آبی می‌کنند
  • حس لیز خوردن دارند
  • با اسیدها نمک + آب می‌سازند
  • مثال: صابون، مایع ظرفشویی، NaOH

💡 نکات مهم

📌 pH چیست؟

مقیاسی از ۰ تا ۱۴ که اسیدی یا بازی بودن را نشان می‌دهد:
• pH = ۷ → خنثی (آب خالص)
• pH < ۷ → اسیدی
• pH > ۷ → بازی

📌 شناساگرها

موادی که با تغییر رنگ، اسید یا باز را تشخیص می‌دهند: کاغذ pH، فنل‌فتالئین، تورنسل.

📌 نکات ایمنی

اسیدها و بازهای قوی خطرناک‌اند — هرگز بدون دستکش و عینک با آن‌ها کار نکن!

🔥 واکنش‌های مهم

⚖️

واکنش خنثی‌سازی

اسید + باز → نمک + آب

HCl + NaOH → NaCl + H₂O
هیدروکلریک اسید + سدیم هیدروکسید → نمک + آب
💨

اسید + فلز

اسید + فلز → نمک + گاز هیدروژن

Zn + HCl → ZnCl₂ + H₂↑
روی + اسید → نمک + گاز هیدروژن
🧪

اسید + کربنات

اسید + کربنات → نمک + آب + گاز CO₂

CaCO₃ + HCl → CaCl₂ + H₂O + CO₂↑
سنگ آهک + اسید → نمک + آب + دی‌اکسید کربن

📊 خلاصه واکنش‌ها

واکنش محصولات
اسید + باز نمک + آب
اسید + فلز نمک + گاز هیدروژن
اسید + کربنات نمک + آب + گاز CO₂
باز + فلز معمولاً واکنش نمی‌دهد
