📖 اصطلاحات جبری

📌 جمله جبری

هر بخش جدا از عبارت — با + یا − جدا می‌شود.

در 3x² + 2x − 5 سه جمله داریم: 3x²، 2x، −5

📌 جملات متشابه

جملاتی که متغیر و توان یکسان دارند.

3x و 5x متشابه‌اند → 3x + 5x = 8x

3x و 5x² متشابه نیستند.

📌 درجه چندجمله‌ای

بزرگ‌ترین توان متغیر در عبارت.

در 3x³ + 2x − 1 درجه = ۳

📌 ساده کردن

فقط جملات متشابه را می‌توان جمع/تفریق کرد.

💡 ضرب و تقسیم جبری

📌 ضرب تک‌جمله‌ای

3x × 4x = 12x²

2x² × 5x³ = 10x⁵

📌 ضرب چندجمله‌ای

2x(x + 3) = 2x² + 6x

(x+1)(x+2) = x² + 3x + 2

📌 تقسیم

6x³ ÷ 2x = 3x²

10x⁵ ÷ 5x² = 2x³

🎯 اتحادهای مهم

اتحادها فرمول‌های میان‌بر برای ضرب عبارات‌اند.

1️⃣

اتحاد مربع دو جمله‌ای (جمع)

(a + b)² = a² + 2ab + b²
(x + 3)² = x² + 6x + 9
2️⃣

اتحاد مربع دو جمله‌ای (تفریق)

(a − b)² = a² − 2ab + b²
(x − 3)² = x² − 6x + 9
3️⃣

اتحاد مزدوج

(a + b)(a − b) = a² − b²
(x + 3)(x − 3) = x² − 9
4️⃣

اتحاد مربع سه‌جمله‌ای

(a + b + c)² = a² + b² + c² + 2ab + 2ac + 2bc
(x + y + z)²
5️⃣

اتحاد مکعب (جمع)

(a + b)³ = a³ + 3a²b + 3ab² + b³
(x + 1)³ = x³ + 3x² + 3x + 1
6️⃣

اتحاد مکعب (تفریق)

(a − b)³ = a³ − 3a²b + 3ab² − b³
(x − 1)³ = x³ − 3x² + 3x − 1
